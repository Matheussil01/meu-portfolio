## Sobre o projeto

O **MFs.dev** é meu portfólio pessoal, desenvolvido para reunir minhas informações profissionais, conhecimentos técnicos e projetos em um único lugar. O site tem uma identidade visual em **preto, branco e vermelho**, com foco em uma navegação simples e em um layout adaptável a diferentes dispositivos.

O projeto foi construído com **HTML, CSS e JavaScript**, sem depender de frameworks para a estrutura principal.

## Funcionalidades

- **Apresentação pessoal:** informações sobre minha formação e meus objetivos profissionais.
- **Projetos:** seção com trabalhos desenvolvidos e tecnologias utilizadas.
- **Habilidades:** apresentação dos meus conhecimentos técnicos.
- **Formação acadêmica:** histórico de estudos em formato de linha do tempo.
- **Currículo:** opção para visualizar e baixar meu currículo.
- **Contato:** seção para facilitar o contato profissional.
- **Design responsivo:** menu adaptado para telas menores.
- **Animações:** fundo com partículas em movimento e efeitos de interação.

## Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/Matheussil01/meu-portfolio.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd meu-portfolio
   ```

3. Abra o arquivo `index.html` no navegador.
